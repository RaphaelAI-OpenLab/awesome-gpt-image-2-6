# Ofox, Quantslant and Kingy source-linked recovery audit

Six existing candidates are promoted with verified, case-specific publisher attribution and source links. There are no local media, embeds or thumbnails in this increment. Four already-known article URLs returned HTTP 200. No new cases were searched for, no API was invoked and no generation was reproduced.

## Ofox (two cases)
The native orange-bird GIF is explicitly described and individually labelled as the result of one Image 2.6 Flare API test. Untested templates and the third-party cat sprite-sheet conversion are not included. The mug experiment names openai/gpt-image-2.6-flare and links two results from the same original with different annotations. It remains one experiment. Both exact prompts are publicly displayed and linked, not copied.

These facts resolve the old model-evidence holds. Usage conditions do not become a licence merely because model attribution is clearer. The .ai terms page returned 403 and was not retried. The independently requested .io terms page, linked by the mug article, returned 200; it distinguishes user-generated content from platform materials but does not establish a licence for these publisher-made examples. No result file was requested or restored. The .io page is not treated as a substitute for the refused .ai terms page.

## Quantslant (one case)
The current benchmark source note explicitly names openai/gpt-image-2.6-flare and openai/gpt-image-2.6-sunburst. The bakery quality ladder is part of that benchmark, and its two output captions identify Sunburst low and max. This connects the specific experiment to 2.6 rather than relying on an article title. One pair remains one case; intermediate quality rows without outputs are not counted.

The existing terms were rechecked and still require written permission to republish images. No such permission has been established. Only source links and our short factual summaries are published, with no copied table, prompt collection, article, original image or derivative. Timings, prices and quality claims remain publisher observations, not independent findings. Full original prompt availability remains unverified.

## Kingy (three cases)
Current individual captions identify the thumbnail, orange product graphic and turquoise edit as GPT Image 2.6 Sunburst. The methodology names the requested API identifier, while distinguishing undisclosed-model ChatGPT web outputs and 2.5 comparison works, all excluded here. The orange image is the stated input to the turquoise edit, not an extra generation.

Earlier direct PNG requests were refused and the corrected recovery explicitly omitted those originals. This batch does not retry those requests, use another download route, restore files from old checkpoints, or embed them. The advertised prompt/receipt ZIP has not been opened. No full-prompt availability claim is made. The already-published rocking-bottle GIF is unchanged.

## Verification limits
This pass checked primary-page text and exact media URLs in markup only. It did not inspect image pixels or files, measure frames, verify cryptographic provenance, or reproduce a generation. Media descriptions are labelled as publisher reports. Attribution and public accessibility are not licences. All retained media URLs use link-only with null local paths. The repository MIT licence does not cover third-party source media.

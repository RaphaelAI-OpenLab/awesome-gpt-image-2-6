# Five-source local backlog audit — 2026-11-08

## Scope and result

Added 22 previously collected workflows: Replicate 7, CSuite 3, Aruru 2, Overchat 5 and IskraGen 5. The 239 published baseline records are unchanged. No new-case search or generation was performed. Only the seven known original pages were revisited; retained original media were not downloaded again.

31 original media files total 9,665,785 bytes: 3 GIFs, 2 MP4s, 6 JPEGs, 1 PNG and 19 WebPs (one animated). All 488 decoded frames/stills were visually reviewed. Original bytes, SHA-256, dimensions, roles and URLs were checked. No EXIF GPS fields were found in the 29 image files. This is not cryptographic authentication of content credentials.

Exact media URL and SHA-256 checks against the other 618 recovered candidates found no cross-case duplicates. A first-frame 64-bit dHash screen against 521 decodable earlier files found no pairs within five bits. This is a screening aid, not exhaustive semantic duplicate detection; non-decodable/video-only prior files were not part of that perceptual comparison.

## Evidence and limits

- Replicate: embedded succeeded predictions match each exact output/input URL, creator, served model and model log. These are public source-reported execution records, not independent API reruns. The lighthouse animation belongs to the recorded openai organization account; the other six predictions name lucataco. The two input images remain references with unknown original models.
- CSuite: both known model pages label their three output tiles and identify Replicate. Flare/Sunburst outputs of the same task form one case. The complete exact prompts remain unverified.
- Aruru: the article attributes its two demonstrations to ChatGPT Images 2.6, without establishing a served variant. The flying-polar-bear record previously contained an unsupported claim that an original model page published its prompt; that sentence is corrected. The coffee prompt example does not prove the complete actual run prompt.
- Overchat: comparison collages include GPT Image 2.5 controls and, where shown, an input reference. Only explicitly labeled 2.6 panels are target outputs. The chef and mascot/sneakers assets are original MP4s, not newly obtained GIFs. The Ember & Rye file is a raster preview; it is not an editable SVG.
- IskraGen: Economy is a provider label, not an established Flare/Sunburst identity. The paper-plane original is a four-frame animated WebP, not a GIF. The 2K mug has an opaque background, and the source says the provider did not pass the background parameter; this is not a demonstrated model transparency failure.

# Ophanim opening stills: source and media notes

Reviewed 2026-11-06 using retained collection records and local media. Source pages were originally observed on 2026-11-05; no new source request or model generation was made for this review. Model attribution is creator/publisher-reported, not an independent reproduction.

The source article attributes these four opening stills to GPT Image 2.6 Sunburst and attributes its subsequent animation to Seedance 2.5. Only the still JPEGs are included. The supplied JPEGs are 1024 × 1536 (2:3), despite the source article’s reported 9:16 format label. The village and subway prompts are shot plans that the publisher says also generated the opening stills; no replacement image prompt is reconstructed.

All listed local files match their recorded byte counts and SHA-256 values and decode successfully. No location or private-account metadata was identified in the inspected files. The Ophanim JPEGs retain a routine encoder comment. These file checks establish local integrity, not model provenance.

Original prompts remain linked at their source. Full prompt text is not reproduced here. Each asset remains source-attributed: no redistribution license was verified, attribution is not permission, and the repository MIT license does not cover these media files.

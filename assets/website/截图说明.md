# 网页图库截图

当前 README 使用 `gpt-image-2-6-prompts-20261113.jpg`，来自 [GPT Image 2.6 提示词图库](https://raphael.app/gpt-image-2-6-prompts)，截取日期为 2026-11-13（北京时间）。

这是实际网页的英文界面截图，包含页面标题、提示词输入区、GIF Lab 和全部提示词的分类标签。使用浏览器截图接口截取页面顶部区域，保存文件尺寸为 767 × 1318；保持页面原有内容，未重绘文字或调用生图服务。

截图和“浏览 Raphael GPT Image 2.6 提示词图库”按钮均打开这个图库页面。分类标签另行打开相应语言的分类网页；网站的 130 条总数和 8 类数量记录于 `content/web-gallery.json`，核对时间为 2026-11-13。分类可以交叉，分类数量之和不作为总数。

更新时重新截取实际页面，同步 `scripts/homepage.py`、`scripts/validate.py` 和本说明中的路径。页面文案、数量与默认模型代表截图时的状态。

旧文件 `raphael-homepage-20261110.png` 是 2026-11-10 的 Raphael 首页历史截图，已不用于当前 README。
